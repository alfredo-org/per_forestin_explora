# Fuentes de objetos

Un `.blend` por objeto reutilizable; exportar su colección explícita a
`game/assets/props/`. Definir origen, escala métrica y superficie de apoyo antes
de integrar señales, equipamiento u objetos de misión. Mantener colisiones e
interacción en la escena de Godot para no mezclarlas con el modelo fuente.

Registrar licencia y autoría de cada asset externo; compartir materiales cuando
la apariencia y el presupuesto de renderizado lo permitan.
